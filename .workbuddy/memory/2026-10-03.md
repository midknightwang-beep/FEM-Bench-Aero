### ⚠️ 关键实测事实：CalculiX `FORC` 语义（**已用翼盒锚定，别再靠叙事推理**）
- **翼盒**（集中载荷、方向是 **+y** 不是 z！）：受力端节点 `Fy = +500.00046 N`，
  钳固端 `Fy = -500.00017 N`，**全模型三向和 ≈ 0**。→ FORC = 该节点总外力
  （自由节点=外载，受约束节点=反力），**全模型求和恒为 0**。
- **平板**（分布压力）：`*DLOAD E_PANEL, P, -0.0001`，`*BOUNDARY NEDGES, 1, 3`（平动，D6 ✅）。
  - 全部 11761 节点 `Σ FORC_z = -0.00001 N` → **全局平衡严格成立**。
  - 轮廓 400 节点 `Σ FORC_z = +35.3704 N`，内部节点 `-35.3704 N`。
  - 支撑反力 = `Σ_轮廓 FORC + 轮廓上的压力集总` = `35.3704 + 0.6296 ≈ 36.0000 N` = q·A ✅（残差 0.01%）。
    **压力集总量级 = 36 N 的 1.8%**，比容差大 10 倍，**不能省**；但它必须**由网格预测**、不能拟合。

### ⚠️ 我自己的两个检查 bug（本轮修正，模型本身没问题）
1. **结点集合选错**：`equilibrium` 用了"去角点"的四边并集。四个角点合计 **-0.62 N**
   （量级与压力集总修正项相当，符号与经典简支板 `2Mxy` 角点力一致），
   于是检查在"平衡到 1e-5"的模型上报出 **200% 误差**。
   → 修正：平衡检查用**完整轮廓（含角点）**；去角点的四边拆分**只**给对称性检查用。
2. **符号搞反**：`applied` 写成 `-q·A`（向下），而反力是 `+q·A`（向上），
   相减得到 200% —— 一个纯符号错也能伪装成"物理错了"。
3. **"四边反力应相等"对加筋板是错的**：长桁沿 y 跑，x 边与 y 边是**不同构件**，
   实测 x 边各 3.33 N、y 边各 14.65 N。正确的对称性陈述是**对边相等**
   （实测 x0/x1 差 0.08%、y0/y1 差 0.06%）。原来比四边 → 报 77% 误差。
4. **崩溃（KeyError）**：`report["runs"]` 存 coarse/fine，而对称性用的新算例存在
   `invariants`，末尾却从 `runs["plain"]` 读。→ 新算例按自己的 label 存回 `runs`。
5. 容差落地：`TOL_EQUILIBRIUM = 0.5 %`（实测 0.005% / 0.02%），
   `TOL_SYMMETRY = 3.0 %`（实测 0.06–0.08%，但**素板 1.8%** ——
   这是 frontal-Delaunay + blossom 网格不镜像对称的产物，容差由网格假象定、不是由物理定）。

  两棵树各自的 `model.inp` 里数字完全相同 ⇒ 旧「S3R 是两码读法不同」彻底证伪。
- **选型**（`diagnostics/probe_tri3.py`，5 模型 × 6 配置，落盘 `probe_tri3.log`）：
  | 配置 | ribs3_chord800 | ribs5_chord800 |

  | alg1（第一遍） | tri3=**8**，minJ 0.5973 | tri3=**16**，minJ 0.5950 |

  | alg1 + `Mesh.Algorithm=8` | **18**，minJ **0.0241** | **28**，minJ 0.0241 |
  | alg2 simple-quad | 0，+8.9 % 单元 | 0，+15.1 % |
  | **alg3 blossom full-quad** | **0**，+0.5 % | **0**，+4.8 % |
  ⇒ 选 alg3。**`Algorithm=8` 反而会把「Jacobian」那道闸弄挂**，值得记一笔。
- **实现（按模型自适应，不动默认）**：`meshing.build_mesh` 拆成
  `build_mesh` + `_mesh_and_census(gmsh, spec, geom, algo, escalated=False)`；

  gate 加 `tri_count == 0`。`_configure_size_field` 多一个 `recombination_algorithm` 形参。
  **踩到的坑**：① 探针的 `_configure_size_field` monkeypatch 包装器没跟上新形参 ⇒ 全 ERROR；
  ② 探针若不禁用自动升级就测不到「第一遍」的三角数 ⇒ 改成**显式钉住算法**（spec 显式非 0 时升级不触发）；

  按「怎么选的」而非「选成了几」生成文案。
