### 做了什么

- **R62**（新红线）：claim 正文里的计数必须等于 artifact 里的计数。
  `sha256` 只证明「文件没被换」，**不证明「文件里写的数是对的」**——两层校验缺后者，
  数字漂移在 sha 层面完全不可见。
- **S-48**（`gate3_counts_consistent`）四条判据：
  (a) 三计数逐项相等 `N field` / `N scalar-disp` / `N reported-only` == `evidence_levels`；
  (b) 加和闭合（三者之和 == `n_cases`）；
  (c) 构成闭合（`N 条 d36` + `N 条 <日期> 实测` == field）；
  (d) 分母对齐（`不说 N/N` == `n_cases` 且分子==分母）。
  **任一计数解析不出来一律判红，不得 skip**（锚点缺失与写错同罪）。
- **NC-53 四向**：正向过 / field−1 红 / scalar-disp−2 红 / d36+1 红 / 删分母红。
  全部用正则**从当前正文现取**，不写死数字（NC-49 踩过的坑）。
