## 两条设计决定（值得记）

- **不是「项数 == 行数」一条**：立项时一跑就撞出三类，项数只能抓其中一类的一半。
  六条判据 = 权重和 / 合计复算 / 三口径同量两处声明 / 项数 vs 行数 / 每段算式复算 /
  段 B 成绩单得分 == 达标 a/b。
- **解析不到即判红，不 skip**（负控五条 ③）：否则「改个措辞」就能让闸失效，而改措辞比改数字容易。
  无法复算的行（三口径的「A+D」）**必须显式标「无算式」并由闸单列点名**。
  ⇒ **遗留待拍板**：A+D「~71%」没有可复核基数（加权算是 92.1%，定义是「30 天关键判据」）。
