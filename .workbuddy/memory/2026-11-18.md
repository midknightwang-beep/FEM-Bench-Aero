## C5 补云图（4/6 → 5/6，2026-11-18 傍晚）

检索词：C5 云图、von Mises、显式三角剖分、Kt 2.51、Delaunay 会填孔。

- **实现**：`_render_contour()` —— `post.load_any(frd)` 取 `STRESS` 块（8682 节点，逐节点 6 分量）
  → `post.von_mises()` → `tricontourf`。色标**固定 0…峰值**（跨工况可比），叠极细网格线（alpha 0.12）
  说明「这是算出来的场不是色块」，热点用白圈 + 数值标注（与表中 max_vM 同源）。
- **★ 关键坑：三角剖分必须显式给**（每四边形拆两三角），**不能交给 Delaunay** —— 自动剖分会把
  孔内部连成三角形，画出来是「孔被填成色块」。而且它看起来像那么回事，只有对着几何才知道错了。
  这与 P2 阶段「求解器 artifact 冒充物理差异」同族：**默认行为在正常输入上是对的，在带洞几何上静默错**。
- **物理验证（看图 + 算数，两条独立）**：
  ① 形态：红色集中区在孔的**上下两端**（垂直于载荷方向）、左右是低应力 —— 开孔板拉伸的经典蝶形；
  ② 自洽：净截面平均应力 = 4000/((200−40)×2) = **12.50 MPa**，Kt = 31.32/12.50 = **2.51**（量级正确）。
     **与 Peterson/Howland 图表比对未做**，报告里明写「属 C7 锚定、另立任务」——宁可标注不可补数。
- **HTML 1.73 MB**（4 张图 base64）。demo 已更新入库。
- **六环对账**：NL ✅ / 求解 ✅ / 云图 ✅ / 报告 ✅ / 生成 🟡 / 澄清 ❌ ⇒ **5/6**；
