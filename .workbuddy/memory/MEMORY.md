### A. 判据设计（写判据的人最容易被判据骗）

- **★★★ 判据不能依赖顺序/位置/时间戳**（`max(mtime)`、`i % 3`）⇒ 问「**shuffle 一下数据集，这条还是这道题吗**」。
- **★★★「默认拒绝 + 手抄名单」必然漏**，且**名单里的「具体值」比名单本身更危险** ⇒ 结构性规则 + 一条**不读名单**的判据（从源库现取、双向：缺了红、多给也红）。**判「某集合该有什么」时，若该集合由被判对象生成，这条判据等于没有。**
- **★★★ 判据自己漏了比没判据更危险**：正则/子串抽取会**静默跳过整类样本**（占位符紧贴冒号那类被整条跳过 ⇒ 删掉一条规则自检照样全绿）⇒ **改 `ast` 按语法边界抽，并先拿已知命中样本验召回**。
- **★★★ 规格常量与生成常量必须分开**（N-26）：同一个常量同时决定「生成几条」与「断言应有几条」⇒ 同步改则等式**永远成立**。**问「这个差异是不是由被断言的东西自己供给的」。**
- **★★★ 文字与代码的一致性不能靠手写**（R77 ⑧）：规则表 + 由表**渲染**文字、数字从探针取；闸 = 双向实测（越界必拒**且**合法必放）+ 区块逐字节 diff。**不做「关键字判文本对错」的闸**（换个说法就绕过，还养成假安全感）。
- **★★★ 同名字段不保证同源**：`grep` 一把抓会把无关文件聚进来（74 vs 实际 64）；**掩码轴与题型轴正交、只是碰巧重合**。⇒ **先问「这个字段来自哪一层」，再决定能不能加/顶替**。
- **★★★ 散文里的数字必须自带算式**（T-R2）：看板三处漂移**全都「一直都在」**（最久横跨 8 个版本），共同点是**数字只被人读，而人只在写那一段时读它**。⇒ 每个数旁边站一个**能被机器复算的算式**，解析不到判红不 skip；**能算了就必须算**（不许用「已豁免」躲掉）。
- **★★ 核了左边忘右边 = 核了一半**：`a/b = p%` 只复算 `a/b`、不核写着的 `p` ⇒ 把右边改错闸**全绿**。凡「等式」都要核两端。
- **★★★「A ⊆ B」要核两端，否则静默全绿**（T-L27c v2）：只遍历 A 去 B 里找 ⇒ **A 自己被删一条时那条不再被遍历** ⇒ 断言返回空、全绿。修法 = 先核 **A 自身完整性**（契约条数）再核成员关系。**问句：这条「A ⊆ B」的断言，如果 A 被改坏了，还有谁会报错？**
- **★★★ 加题压不下整体退化率，分层报才是价值**（T-L27c）：老卷最坏 31/64 仍可命中，要摊到 10% 需再加 **246 条** ⇒ 加题真正的收益是**两层分开报**（「该答⇒保真」／「该问⇒键名对」，**不可相加或比大小**）；`_coverage` 必须写明覆盖哪层（只覆盖一层时另一层 `0/0` **不是 0 分**）；**分层必须按族取整**。
- **★★★ 两个判分器不一致 = 实现漏项，不是口径差异**（T-L27b）：一个早有「ec=0 ⇒ 该答不答」分支，另一个在 `if spec:` 里不看 ec ⇒ 把正确 spec 判成编造（实测 59/59）。**加新题型/改卷之前先问「目标判分器认识这种题吗」**；守它 = 自比 A==A + 三向变异。
- **★★★ k 遍多数表决要两级 + 全同短路**（T-B2B5 v4）：直接取众数会 1/1/1 无解 ⇒ 一级只判「是否拒绝」严格过半，二级在同票类定细分、平票取保守值；**「无输出×3」若被二元化成 invalid×3 ⇒ 变成「判不了」，把一致的失败误当不可判**。守它的是**自比 A==A**；`over_refuse` 必须归 `refuse`（否则过拒被洗成建对）。
- **★★ 正则交替顺序写反 = 假红**：`\.(?:json|jsonl)` 把 `x.jsonl` 截成 `x.json` ⇒ **长选项永远排前面**。
- **★★「提及」≠「引用」，也≠「点名」**：按 basename 找引用 ⇒ token 必须含 `/`；整行扫 `NC-\d+` 会把正文描述当清单点名 ⇒ 只从结构化清单段读。
- **★★ 指标选错比判据写错更隐蔽**：用「对照建对率」当「拒答题可否单独引用」的门槛 ⇒ 把建模能力的锅算到拒答头上。**每个门槛先问「它失败时责任该算在谁头上」**。
- **★★ 过滤写在收录之后 = 没有过滤** ⇒ 先判整句归属再收片段。**同一组探针不能给两侧共用**（`inside` 带 `mutate` ⇒ 合法值也塞未知键、必然被拒 ⇒ 自相矛盾地红）。
- **★★ 一个单元格里只许出现本段该有的算式**（T-R2 余波）：补一句 `35/40 = 87.5%` 会让闸把它当「完成度算式」判红。**这是闸的正确行为**，改措辞（`35/40（87.5%）`），**不是放宽闸**。

### B. 测量错误（工具错了，结论越像真的）

- **★★★ 两侧字集不同时 `comm` 双向误判** ⇒ `git -c core.quotepath=false ls-files`；**先问「两侧是不是同一套字符集」**。
- **★★★ `$?` 会被管道吃掉** ⇒ 被测命令后不能有任何命令，重定向到文件再取 rc。
- **★★★ 闸做得越好，越看不出上游不同步** ⇒ **先问「闸替它吸收了什么」**。
- **★★★「主仓全绿」证明不了「新分支被跑过」**（短路分支）⇒ 新分支必须在**能走到它**的环境里验；验不到就明写「本向未验证」。
- **★★★ 工具必须读规则表，不能另立一套**；**不要把成功建立在 git 的惰性行为上**（`checkout-index -a -f` 后 928 个 LF 一个没变、rc=0）⇒ 自己写字节、自己验字节。
- **★★★ 空的东西最干净**（bundle 不带 `HEAD` ⇒ verify/fsck/status/clone 四信号全「成功」而工作树 0 文件）⇒ **判据落在根因**。
- **★★★ 行尾规范化会改掉产物里嵌的 sha**（T-L27c）：卷 LF→CRLF 后 `tasks_sha256` 变了而成绩单是规范化**之前**生成的 ⇒ 嵌入值过期且**无人报错**。**顺序固定：先规范化卷 → 再生成嵌 sha 的产物 → 最后 add**；改完回查「产物里的 sha == 磁盘上的 sha」（NC-80 守）。
- **★★ 验证产物本身会过期且无声** ⇒ **「完整」和「当前」是两个判据**，后者只能靠 `behind_by` 问；用「当前 HEAD」造旧包等于没造。
- **★★★ 单配置的测量会把「缺陷」读成「运气」**：同一句歧义规则，glm 0/20（没按字面核）而 ds 6/6 全拒 ⇒ 只跑一个模型会得出「prompt 没问题」。**换第二个模型的价值不是排名，是让同一段文字有第二个执行者**；两模型稳定性还能差一个量级（零翻转 vs 翻 11 条）⇒ 弱稳定模型的单次数**必须带另一遍的值**。
- **★ `SIGTERM` 杀父进程 ≠ 杀子进程**：残留子进程抢 `.solve.lock`，表现为满屏 `pipeline: False`；后台任务还会被系统挂起 ⇒ 长任务「一批一个任务 + 阻塞取输出」。
- **★ docstring 里的相对路径按 CWD 解析，不能照抄** ⇒ 一律传**绝对路径**；且 `--emit` 写完必须 `--check` 同一路径（否则「生成了」≠「生成在正确位置」）。

### C. 证据与锚点

- **★★★ 加闸前先问「谁触发这个闸」，触发器自己有没有闸**（hook 不入库 ⇒ 新 clone 后静默消失）⇒ **判据不能放在被它守护的东西里**。
- **★★★「门禁全绿」只证明工作区好，不证明提交好** ⇒ 对提交本身 clone 复验；`check_commit.py` G4 守它。
- **★★ sha256 只证「文件没被换」不证「数对」** ⇒ claim 计数要有闸比对 artifact；**建完闸先查自己刚写的东西有没有绕开它**。**无工具读的 = 无闸**（R58）。
- **★★★ 同一类闸只装在一个调用点 = 没装**（T-L27c）：一个评分器有 `require_dataset`、另一个从来没有 ⇒ 前者硬错、后者**静默出假成绩**。**加/改评分器时先横向问「同类闸在另一个评分器上装了吗」**。
- **★★★ 只证「没改坏」不证「改对了」**（T-L27c）：等价脚本只能挡「改了冻结卷的行为」，**挡不住「改动根本没生效」**（把整段删掉，两个冻结卷照样全等价）⇒ **必须另加一条正向判据**（新能力真的解析到真实对象），从数据现取不硬列。
- **★★ 前置闸用 `isdir` 挡不住「有但是空的」** ⇒ 校验**内容量级**；问「**这个闸有没有可能被空壳满足**」。

### D. 负控

- **★★ 负控五条**：①不只断言「是否红」，还要断言**「红的原因对不对」**；②变异锚点**现取不写死**；③锚点缺失判红不 skip；④新闸测「自比 A==B」；⑤消掉漂移面要配闸防它长回来。
- **★★★ 变异锚点写死的不是数字，是「基线长什么样」**（三次复发）⇒ 问「**这个差异是不是由基线状态供给的**」。
- **★★ 闸与负控可能互为前提**（S-45 读上一轮 JSON ⇒ 改名后首跑必红、重跑自愈）⇒ 新增负控**先改 INDEX 累计数**再跑。
- **★★ 放宽必须有边界（R69）**：①哪里仍必须为 0 ②例外带 reason ③例外不进对外数字。**能判的不变量优于需维护的名单**。
- **★★ 子串匹配的假通过是「静默偏高」**（R70）⇒ 纯 ASCII 加词边界，**中文别名仍按子串**；**同一通道双向**，也修假红 ⇒「这次只会更严」的直觉是错的。
- **★★「自比 A==A」可升级成「纯增量」**：有意新增报告字段后逐字节必然不同，但「旧叶子一个不丢/不改 + 新增只许落在指定路径」**比逐字节更严**（逐字节挡不住「顺手多写一个数字」）。
- **★ 只留最新一份**（`negative_controls_<N>.json`），旧的 `git mv` 到 `reports/archive/`，INDEX 同步加编号。
