## 高价值坑（细节查当日日志）
- **「模型不行」第一嫌疑 = 特征没给全，不是数据没用（2026-10-24 M7）**：首轮岭回归只给 7 特征表示 10 个真实自由度（漏 `is_T`、`web_pos`），test 14.8 % 输给 3 参物理模型；补齐后翻转到 **10.7 %**，结论完全反转。同理**诊断假设与被测对象必须同口径**（距离在 10 维算、误差取自只看 sweep/taper 的模型 ⇒ corr −0.009 毫无意义）。
- **标准化欧氏距离不能当可信度指标**（M7 实测 `corr(distance,|err|) = −0.046`）：`sweep40` 距离 1.65 却错 41.5 %，`str3_T` 距离 4.90 却只错 4.8 %。可信判定必须**逐轴判训练包络**，并按轴分级：`n_ribs` 外推安全（<3 %）、`is_T` 可接受（4.8 %）、`n_web`/`taper` 中等（11–15 %）、**`sweep` 外推危险（20→40° 错 41.5 %，超线性）**。
- **补覆盖点 ≫ 补同质样本**：wingbox 学习曲线 n=10→12 加两条同质 chord800 变体 test 14.1→14.2 %（零收益），n=12→13 加唯一带腹板的 web1 → **10.7 %**。放量必须先补「新轴/新形式」的锚点。
- T1 **放样≠拉伸**（退化不走 addThruSections）；平板闭式用 √(σx²−σxσy+σy²) 非 6Mx/t²；T4 **Kt 不带口径就不是数**（gross/net 差 11.1%），**Howland 只看 λ**（D28：同 λ 跨 coupon Kt 必同，闸只打 ccx 侧、真闸=同码跨 coupon 差）；T6 **剪流是决定性可观测量**（载荷=弯曲+端部扭矩，扭转率用面内刚性转动 LSQ）；翼盒 vM 别用 inplane（丢全局 sxz）；T7 **size 单维须 hole_d 随 width 缩放钉 λ**；**复材对照 = CLT 等效模量**（加载端平均恒等式口径，TOL_EFF=3% 按实测链钉）；两码「力」不同（ccx FORC=总外力 / abaqus RF=反力）；D8 应力=外表面峰值，**同名同定义但归约不同 ⇒ 峰值禁裸比**；闭包内 `x = f(x)` 自引用 = UnboundLocalError。
- **铺层角度归一化陷阱（2026-10-24）**：判「平衡」时把角度 `% 180` 再求厚度和，会把 `−45°` 变成 `135°` 而与 `45°` 配不上对 ⇒ 合法平衡铺层 `[±45]s` 被误拒。**平衡必须按有符号配对**（`a>90°` 折回 `180−a` 计入负向桶），并**用 A16/A26 实算值交叉校验**（`|A16|<1e-9·max(A11,A22,A66)`）。另：准各向同性铺层可用**各向同性恒等式 `G=E/(2(1+ν))`** 独立验 CLT，不依赖任何铺层公式。
- **膜态厚度维退化（2026-10-24）**：纯拉伸开口板在**恒定名义应力**口径下，`F=σ·w·t` 与膜刚度 `EA∝t` 精确抵消 ⇒ 位移与厚度**逐位无关**（t=1 与 t=2 同为 0.05734516），vM 只差 0.02%。厚度维做样本**零信息量**；它的价值是当**载荷口径正确性探针**（若载荷没按 t 缩放，位移会差 2 倍）。厚度要有可观测性必须引入弯曲/屈曲/面外载荷（`D∝t³`）。
- **只打印不参与判定的检查不是检查（2026-10-24）**：`verify_dataset` 的 pairing 打了 `MISMATCH` 而 `all_ok` 不含它 ⇒ 41 vs 44 条仍报 PASS。凡新增检查项，必须同时并入总判定，否则等于没有。
- **★ 厚度维退化与否取决于载荷口径，不是轴本身的属性（D31，2026-10-24）**：同一根「壁厚」轴 —— T7 开口板载荷 `F=σ·w·t` **随 t 缩放**、膜刚度 `EA∝t`，精确抵消 ⇒ 逐位零信息量；翼盒载荷 `F=500N` **固定**，无抵消 ⇒ `u∝1/t`，skin 1.5→4 位移变 2.656 倍（偏差 0.30%）。**今后判某轴是否退化，先问「载荷随不随它缩放」**。另：翼盒 `skin_thickness` = **主承力壁厚（蒙皮+前后梁+腹板）**，`rib_thickness`（4.0）独立 ⇒ 截面 `I∝t`，别写成「只改蒙皮」。
- **标准化系数不是幂指数（2026-10-24）**：ridge 在标准化空间拟合，`w = d(log y)/d(z_f)`；**指数 = `w / sd(log x_f)`**。漏除标准差会把 `w=0.200` 读成「指数 0.2」。实测翼盒 `span` 隐含 **+2.858**（物理+3）、`skin` **−0.992**（−1）、`chord` **−2.900**（−3，独立旁证）；弱正则 alpha=1e−8 对照 2.875/−0.999 ⇒ 收缩可忽略、指数是真的。
- **交互项必须用实测单轴响应相乘，不能用理论指数（2026-10-24）**：用 `(span/2000)³` 算乘积会把 span 标度自身的 −3% 偏差误报成「交互项 3.09%、test 是陷阱」；改用实测单轴后为 **0.06%/0.17%**（可忽略）。同 M7「诊断口径须与被测对象同源」一类。
