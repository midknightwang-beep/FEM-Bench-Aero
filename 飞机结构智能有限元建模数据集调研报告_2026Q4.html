3 · 智能体自动建模框架与配套数据 本轮新增

这是本轮最重要的发现：2025 下半年–2026 年集中出现了一批「自然语言 → 几何 → 网格 → 求解 → 分析」的端到端 Agent 框架，其中已有直接打在飞机机翼上的。

3.1 FeaGPT —— 首个端到端 GMSA 智能体（航空正例）

FeaGPT: an End-to-End agentic-AI for Finite Element Analysis

arXiv:2510.21993 ｜ Yupeng Qi, Ran Xu, Xu Chu ｜ 2025-10-24

链路：自然语言 → FreeCAD Python API 参数化几何 → Gmsh 物理感知自适应网格 → CalculiX 求解 → 数据驱动结果分析 / 参数化研究。

航空验证：对 NACA4412 翼段结构自动生成并分析了 432 个构型（长桁/翼肋/蒙皮装配，自动布尔运算处理多构件相交）。网格 119,627–140,578 个四面体单元（均值 129,390，变异系数 4.6%，R²=0.94），432 个构型全部通过 Jacobian 正定与拓扑完整性校验；12.4 分钟生成全部几何（平均 1.7 s/例），单例网格约 34 s。另用工业涡轮增压器（7 叶压气机 / 12 叶涡轮，110,000 rpm）做过验证。

对本课题的价值：目前唯一一个把端到端 Agent 真正打在机翼结构上的公开工作。它证明了「NL→翼段 FE 模型」可行，且给出了网格质量的量化验收口径（Jacobian、拓扑完整性、CV）。它本身不发布数据集，但其 432 构型流程是可复现的「数据生成器」——这正是我们最需要的自建数据产线。

局限：结构分析为线弹性范畴；网格质量优化在复杂几何上仍待改进；不涉及多物理场与模型更新。

3.2 ALL-FEM —— 语料 + 多智能体框架（已在本地）

ALL-FEM: Agentic LLMs fine-tuned for FEM

CMAME 457 (2026) 118985 ｜ arXiv:2603.21011 ｜ Purdue 等

语料 = 1000+ 条经校验的 FEniCS 脚本（500+ 专家整理代码 + 检索增强的多 LLM 流水线生成并过滤），微调 3B–120B 模型；多智能体编排「问题→PDE→代码→调试→可视化」，带运行时反馈闭环。在 39 个基准（线/非线性弹性、塑性、牛顿/非牛顿流、热流、FSI、相分离、动域输运）上，最佳模型 GPT-OSS-120B 代码级成功率 71.79%，优于非智能体部署的 GPT-5 Thinking。

价值：提供「问题陈述→校验解」的自主仿真蓝图 + 可直接微调的 FEM 语料。局限：基于 FEniCS（变分形式），与飞机结构常用的 NASTRAN/Abaqus/ANSYS（壳/梁/接触/复材）差异大；39 题不含航空几何/材料/载荷与模型更新。

3.3 DeepJEB++ —— 基座模型驱动的仿真标注数据扩张 新

DeepJEB++: Foundation-Model-Driven Large-Scale 3D Engineering Dataset

arXiv:2606.12994 ｜ KAIST + Narnia Labs ｜ 2026-06

从 不到 400 个种子设计（喷气发动机支架），经「2D 潜空间扩散增广 + VLM 可制造性过滤 + 域适应生成基座模型升维到 3D + 自动识别载荷/螺栓界面并赋有限元标签（质量、应力、位移）」三步，扩到 15,360 个带仿真标签的三维支架（40× 扩张），单阶段单 GPU 完成；标签保真度以 SimJEB 真值校验。数据集将公开。

价值：这是目前对「小样本航空结构件 → 大规模带标注 FE 数据」最直接的解法雏形。飞机结构（翼肋、框、接头）正是典型的「种子少、标注贵」场景，DeepJEB++ 的三阶段范式可直接迁移。

4 · 建模与代码生成能力评测基准

这一环回答「Agent 建得对不对」。分两类：文本/代码类和多模态/视觉类，外加 2026 年新出现的统一排行榜。

基准任务与规模许可对本课题的用法
FEM-Bench
（本地已有）		 25–33 个计算力学任务（1D/2D/3D MSA），每题配参考实现 + pytest 单测，递归数值匹配判定；实测已评 9 个模型。 ✅ MIT 建模 Agent 代码生成的回归测试集；在其上扩「壳单元/装配接触/复材层合/模态屈曲」即成本课题的 FEM-Bench-Aero。
StructuralEval
（本地已有）		 25 题「结构图 → 标准 JSON」→ WASM 求解器物理验证；难度 1–5 分级，诊断式评分（几何 0→支座 .25→连接 .50→荷载 .75→完全 1.0），加权准确率。 ⚠️ CC BY-NC 4.0 「图纸/照片 → 可计算模型」的评测基线；思路可复用到飞机结构工程图，但需自建带标注的翼肋/长桁/框板壳图。
FEABench 新 Google/Harvard：LLM 操作 COMSOL API 求解多物理场。Gold 15 题（人工核验、有数值靶值）+ Large 200 题（从 COMSOL 教程解析）+ 768 条标注代码片段库。多智能体（Controller/Corrector/ToolLookup + Verifier）把可执行率从 62% 提到 88%，但没有一个模型能完整正确解出任何一题；物理接口定义是最大瓶颈。 ✅ 开源
github.com/gaoch6258/feabench		 「LLM 直接驱动商业 FEA 求解器」的评测范式；其 Annotated Library 检索增强思路可移植到 Abaqus/NASTRAN 输入卡生成。
PhysicsBench 新 统一排行榜：7 类生成/预测任务 × 9 个数据集（含工业级 CAD/CFD/FEA）× 28 种配置，评测 66 个模型；用 BenchRank 对相关指标去偏排序。结论：大规模学术排名不能预测小样本排名，7 个任务中 6 个的冠军随数据规模变化。 ✅ 开放
leaderboard.narnia.ai		 选型依据：告诉我们在「工业级小样本」条件下该信哪个模型，而不是信论文里的 SOTA。
SciConvBench 新 多轮澄清式任务形式化评测：把「欠定义/自相矛盾」的科学任务陈述，经最多 11 轮追问还原成完整规范（目标/几何/本构/属性/BC/IC/数值/输出/工具 九元组）。覆盖流体、固体力学（含 FE 式任务）、材料、PDE。 ✅ 开放
arXiv 2605.18630		 补上了被普遍忽略的一环：工程需求本身是模糊的。飞机结构任务书常常缺工况/缺约束，这正是 Agent 最容易「静默猜错」的地方。
HoneyComb / MechAgents 材料科学（HoneyComb：MatSciKB 知识库 + ToolHub）与力学工作流的 LLM 智能体系统；工具增强后各任务准确率普遍提升（如 SciQA 上 HoneyBee 提升 45.7 个百分点）。 ✅ 开源 「知识库 + 工具集 + 检索器」的 Agent 架构模板，可直接套到强度分析的知识源（许用值、失效准则）。
一个反复出现的结论：FEABench（COMSOL）与 FEM-Bench 都指向同一件事——LLM 写通用 Python 很行，但「物理块」（本构、边界条件、界面选择）是瓶颈。所以我们的 Agent 设计不能只靠提示词，必须把物理约束做成可执行校验（就像 StructuralEval 用 WASM 求解器当裁判）。

但仓库未公开，当前不可用		 方法论价值高：其「识别→提取→建议」三任务可直接改造成本课题的「读强度结果→定位超限区→出模型修正指令」子 Agent。但不能用——只能等仓库公开或自建同类数据。
注意：上一轮报告把 FRAME 列为可用基准之一。本轮复核后明确降级为「不可用，仅方法论参考」。如果后续要做「结果解读」智能体，替代方案是自建：用本地 Abaqus/Abaqus 后处理的应力云图 + 参数做配对标注，这在工程计算线（odb 提取）上本来是现成的。

6 · 结构强度替代模型（代理模型）数据集

这一类比「代码评测」更接近飞机结构强度的实际业务：给定几何/参数，直接预测应力/位移/失效场。也是本课题「模型高效更新」最可能落地的形式。

SimJEB · 喷气发动机支架

MIT / Eurographics SGP 2021 ｜ simjeb.github.io

381 个众包手工设计的支架（源自 GrabCAD「GE Jet Engine Bracket Challenge」，700+ 参赛稿 / 320 设计者 / 56 国），每个含 CAD、四面体网格、三角表面网格，以及 4 个载荷工况（垂直/水平/斜向/扭转）的 FEA 结果。提供 5 类标量场（位移 x/y/z、位移幅值、von Mises 应力）与 3 组 80/20 训练测试划分，并给出朴素代理模型的 MAE 参考值。

许可：⚠️ CC BY-NC-SA（非商用）。工程代理建模的经典「挑战题」。

复材翼盒失效准则 ML 基准 新

Aerospace Science and Technology 177 (2026) 112878 ｜ 都灵理工

1,017 次有限元仿真的 Cirrus 级碳纤维翼盒：9 个未损伤工况 + 1,008 个损伤场景（28 个层内损伤位置 × 4 个严重度 × 9 种正交异性材料）。在最受力单元上评 5 类经典失效准则（Max-Stress、Tsai-Wu、Tsai-Hill、Hashin、Christensen）作监督标签；RF/SVR 代理，材料级留一交叉验证下 Hashin 指数 RMSE=0.076，Max-Stress ≤0.15。

许可：原文开放获取（CC）；数据需向作者索取。

Z-beam 复材翼物理引导 ML 新

Composite Structures 394 (2026) 120662 ｜ Imperial College

用周期性边界条件生成代表性 Z-beam 单元数据集，子模型 + LaRC05 准则算失效指数；物理引导框架（嵌入弹性线性、应变-失效指数单调性）预测失效指数、主导失效模式与临界位置。

价值：「物理引导 + 数据高效」的范式样板，适合种子数据稀缺的航空场景。

CarCrashNet · 结构撞碰 新

arXiv:2605.07098 ｜ MIT + Toyota RI

14,000+ 保险杠梁-柱撞仿真 + 825 次整车撞碰仿真（Dodge Neon / Toyota Yaris / Chevrolet Silverado 三款车型）；基于开源 OpenRadioss 的 FE 流程已对实验数据与 Ansys LS-DYNA 双验证；配套 CrashSolver 神经求解器在全部数据集上误差最低。

许可：✅ 开源（github.com/Mohamedelrefaie/CarCrashNet）。非航空，但非线性/接触/大变形/塑性是航空撞碰分析的同构问题，且模式（开源求解器 + 商用求解器双向验证）值得照抄。

SeisGPT · 结构响应基座模型 新

Nature Communications 17:8884 (2026) ｜ 同济大学

物理信息基座模型：200 万+ 非线性弹塑性仿真（由 27 万个自动生成的合规设计 + 694 栋真实建筑构成，超 100 亿响应时间步）；未见建筑上位移/加速度预测归一化误差 <5%，相对传统 FEA 约 40,000 倍加速；可融合稀疏传感器重构全楼响应。

许可：⚠️ CC BY-NC-ND。对象是多层建筑（非航空），但「自动生成合规设计 → 批量仿真 → 基座模型 → 稀疏传感重构」这条产线是可直接迁移的模板。

12 · 关键缺口（必须自建的部分）

缺口现状建议动作
① 飞机结构专用的 FE 代码/模型语料 ALL-FEM 是 FEniCS 变分形式，FEM-Bench 是教材级 1D/2D/3D 梁，没有一条覆盖壳/长桁/框/复材层合/接触。 以 FeaGPT 的 432 构型流程为模板，用 FreeCAD+Gmsh+CalculiX 批量生成翼段/壁板模型，扩出 FEM-Bench-Aero 与 FEniCS 之外的第二套语料。
② 从工程图/自然语言到飞机结构模型的测评集 StructuralEval 只有梁/刚架/桁架 25 题，图片是简化示意图，非航空。 复用其「图→JSON→求解器验证」闭环与难度分级评分，自建带标注的翼肋/长桁/框板壳题集。
③ 模型更新的监督信号 只有 M001（原始 vs 更新后）、Hawk T1A、arXiv 2604.03788（子结构刚度修正因子）三处可用，总量很小。 以「子结构刚度修正因子」为标签形式，用本地 Abaqus 模型 + 试验/仿真模态造自己的更新对。
④ 结果解读基准（FRAME 缺位） FRAME 仓库至今未公开，当前完全空缺。 用工程计算线的 odb 提取成果，把应力云图 + 参数 + 结论配对成标注数据，自建「读云图→定位超限→给修正建议」数据集。
⑤ 合规语境 所有公开集都缺适航/认证语境（安全系数、失效准则、载荷谱）。 把 MMPDS/NCAMP(CNCAMP) 作只读权威源接入 Agent，把「许用值校核」做成不可绕过的硬约束检查。
⑥ 国内数据获取门槛 nbsdc 需注册 + 申请表盖章审批，「完全共享」≠「零门槛」。 提前走流程；同时优先用无门槛的 NASA/FAA/Zenodo 源做预研。

13 · 执行摘要

一句话结论：本轮调研确认，「通用 FEM + LLM」的地基（语料、评测、框架）已经基本够用了，缺的是「飞机结构语义 + 试验真值」这两块。课题的投入重心应该从「找公开数据集」转向「用现成框架批量自建航空数据」。

本轮最重要的 6 个发现

  1. FeaGPT 证明了端到端可行。自然语言 → NACA4412 翼段几何 → 自适应网格 → CalculiX 求解，432 个构型全部通过雅可比与拓扑校验。这是目前唯一把 Agent 真正打在机翼结构上的公开工作，其流程可直接当我们的数据生成器。
  2. FRAME 仍然不可用。上一轮列为可用，本轮复核确认仓库未公开。结果解读这一环目前是空的，必须自建，或等其公开。
  3. 真机试验数据有两条新线索。FAA EMST Panel 1（全尺寸机身金属壁板 + ARAMIS 全场应变，887 MB，美国政府作品、许可干净）和国内「变体飞行器结构设计数据集」（哈工大，含 STEP 模型 + 风洞/变形试验）。再加上 Hawk T1A 与 M001，构成了更新环的可用底座。
  4. 国内源此前被完全忽略。nbsdc.cn 上有至少 6 条与航空结构/复材直接相关的公开数据集（金属基复材构件考核、飞机复材壁板、复材多尺度损伤本构等）。门槛是盖章审批，不是「没有」。
  5. 「小样本 → 大规模」的解法已经出现。DeepJEB++ 用基座模型从不到 400 个种子扩到 15,360 条带仿真标签数据（40×）。这正是航空结构「种子少、标注贵」的标准解法，值得优先复现。
  6. 模型选型别信论文 SOTA。PhysicsBench 用 66 个模型 × 28 种配置证明：大样本学术排名不能预测小样本排名，7 个任务里 6 个的冠军随数据规模变化。我们处在小样本区，必须自建小样本评测。
