# 历史叙事（M1–M5 建设过程）

把飞机结构的**建模任务**变成可执行、可判定的样本：给一个规格（结构族 / 几何参数 / 长桁截面 / 平面形状），
有一个**跑得通、且被独立验证算得对**的有限元模型作真值。
M1 落四件套与语义判定，M2 落结构族抽象与「建面打标」分类器，
**M3 落第一批新形式** —— **T5 长桁截面族**（blade → +T 形）与 **T2 加筋平板壁板**
（**第一个真正的第二个结构族**），两者各带退化自检。
**M4 落划分**（等价类 + 角色 + 划分规则），**M5 落平面形状** ——
**T1 后掠 / 锥形翼盒**（把「沿展向刚体平移的等直箱」变成**两截面放样**），
再**放量到 23 条/树**（D16/D17），接着**落第三结构族 T3 机身加筋柱壳段**
（首个**多载荷组合**工况：内压 + 端弯 + 端剪）并**补平板族第一条含长桁的 val**，
到 **26 条/树**（D18–D22）；然后**落第四结构族 T4 开孔板**
（中心圆孔单向拉伸——全库**唯一带闭式解析对照**的族：Kirsch / Howland），
到 **29 条/树**（D23）；最后**落翼盒族的新形式维 T6 多闭室**
（剖面加**贯穿上下蒙皮的中间腹板**，载荷 = 弯曲 + **端部扭矩**，因为闭室数只在扭转下可观测；
有**Bredt-Batho 多闭室扭转**解析对照），到 **32 条/树**（D24）；最后**给柱壳补上尺寸·壁厚维**
（直径 1800 / 长度 1600 / 壳厚 2 的单维外推 3 条 val + 双维外推 1 条 test；
**首个「物理参数维」外推线**，并有**逐尺寸薄壁闭式解**独立对照），到 **36 条/树**（D25–D27）；
最后**给 T4 开孔板放量**（尺寸 / 孔径比 / 偏心 × 孔径比，**D28 补双维角点谓词**；
**尺寸不变性探针**：同 λ 必同 Kt——解析标尺不随试件移动），到 **40 条/树**；
M6 给开孔板补上**材料维 T7 复材层合**（老王拍板**架构 B 等效单层**：CLT 把对称均衡铺层
均匀化成等效正交异性单层，S4 不动，`*ELASTIC, TYPE=ENGINEERING CONSTANTS` 9 常数，D29；
**七种结构形式 T1–T7 至此全部落地**），打样 1 条入库，到 **41 条/树**；
随后 M6 放量**材料维**（D30：开口板四条标量轴计数 —— M 铺层 / T 壁厚 / L λ / S 尺寸，
0 轴 train、1 轴 val、≥2 轴 test），补 `[45/-45]s` 与准各向同性 `[0/45/-45/90]s` 两个铺层点
+ 一个"铺层×λ"双维角点，到 **44 条/树**。**厚度维经实测判定退化、未入库**（恒定名义应力下
`F ∝ t` 与 `EA ∝ t` 精确抵消 ⇒ 位移与壁厚逐位无关，实测 2.0 mm 与 1.0 mm 均为
0.05734516 mm），改立为常设自检 `check_forms :: T7.thickness-invariance`（载荷口径探针）。

**M7 不再往形式上加，转去验证「这些数据到底能训出什么」**（`../feagpt_repro/_probe_m7/`，只读 truth.json、不跑求解器）。
结论是三条硬事实：① 按 D12/D30「只有锚点算 train」算下来，wingbox 可训 **13** 条、open_hole **2**、
barrel **1**、stiffened **1** —— **当前是外推评测集，不是训练集**，只有翼盒够做代理建模；
② 六档对照（max_disp MAPE）实测：常数 **34.95 %** ／ 纯梁标度律 **31.60 %** ／ 梁+形状 3 参 **14.84 %** ／
岭回归 10 特征 **10.72 %**（内插 LOO 3.97 %）／ GP **13.95 %** ／ 物理+岭残差 10.63 % —— **n=13 时线性胜非线性**；
③ 学习曲线证明 **补覆盖点 ≫ 补同质样本**：加两条同质 `chord800` 变体 test 14.1→14.2 %（零收益），
加唯一带腹板的 `web1` 则 14.2→**10.7 %**。逐轴外推风险分级（实测可当使用规则）：`n_ribs` 安全（−1.9/−2.8 %）、
`is_T` +4.8 %、`n_web` +14.5 %、`taper` −11.1 %、**`sweep` 20→40° 为 −41.5 %（危险，超线性）**。

于是**D31 给翼盒补尺寸维**：`span` 与 `skin_thickness` 从 D25 式「精确锚点」**扩为 train 区间**
（`WINGBOX_TRAIN_SPAN = (1600, 2400)`、`WINGBOX_TRAIN_SKIN = (2.0, 4.0)`），核心二分是
**「出区间 = 外推（val/test）、出锚点但仍在区间内 = 扫点（train）」** —— D25 说「连续维只采过一个点 ⇒ 只能等号」，
反过来**主动补档位就造出 interior**，区间才诚实。补 8 条（4 train / 2 val / 2 test），到 **52 条/树**
（**51 个等价类**、**train 21 / val 17 / test 14**）。补点后模型真学到了幂律：M3 test **10.72 % → 8.32 %**、
train LOO 3.29 %，常数基线 44.53 %（相对基线 30.6 % → **18.7 %**），回归出的隐含指数
`span +2.858` / `skin −0.992` / `chord −2.900`（物理 3 / −1 / −3，弱正则对照 2.875 / −0.999）。

**D32/D33 再接一手**：D32 把**标量代理目标口径**定死 —— 主 `max_disp`（= 弯曲挠度）、副 `max_w`
（只报不判，仅做 `span` 指数交叉检验）、应力峰值**不设为可学目标**。D33 给后掠轴补中间档
（`sweep_deg` 20° → 30°，train 站 0/10/20/**30**），把 `sweep40` 的外推距离从 20° 缩到 10°。
实测（`_probe_m10/`）：后掠响应**超线性**（相对 0° 的位移比 1.000/1.094/1.340/1.853/2.965，增量严格递增），
0–20° 割线外推到 40° 差 **−43.4 %**；补 30° 后 `planform_out` 组 **32.9 % → 25.7 %**（−7.2 pp）、
主目标 test **7.96 % → 7.74 %**，代价是 `combo` 组 4.6 %→7.0 % 与副目标 `max_w` 4.17 %→8.33 %。
**净收益 0.22 pp 落在 n=7 的噪声里 —— 方向对、剂量不足，sweep 40° 仍是全表最大误差项。**
到 **53 条/树**（**52 个等价类**、**train 22 / val 17 / test 14**）。

※B5（batch5）一件事，口径见 **D24**：**T6 多闭室翼盒 3 条**。**归属**——它是 `wingbox` 族的
**新形式维**，不是第五个结构族（几何仍是同一个 NACA4412 翼盒，只是剖面里多了一道腹板）。

**T6 为什么是「腹板」而不是「又一根长桁」**：腹板**贯穿**上下蒙皮，把单闭室切成 `n_webs + 1` 个闭室；
长桁只贴单侧蒙皮、**不贯穿**，所以不新增闭室。两者在拓扑上必须分开——`web_chordwise` 与
`stringer_chordwise` 也**不许重合**，重合了关 4 就数不清面（`check_forms :: T6.refuses-on-stringer` 钉死这一点）。

**T6 为什么载荷要加扭矩**：闭室数在**弯曲**下几乎不可观测（各闭室同向受载，剪流分布体现不出腹板），
只有在**扭转**下才分裂成不同的 `|qᵢ|`。所以载荷是「翼尖 500 N 上举 + **端部扭矩 1e6 N·mm**」。
解析对照是 **Bredt-Batho 多闭室扭转**：`M q = 2 G θ a`（`M[i][i] = ∮ᵢ ds/t`，`M[i][j] = −(共享壁长)/t`），
`GJ = 4 G aᵀ M⁻¹ a`；`n = 1` 时退化为经典 `GJ = 4GA²/∮ds/t`。独立验证线 `verify_multi_cell.py`
（`--with-abaqus`）实测 **20 PASS / 0 FAIL**：GJ 跨码差 **0.184 %**、逐闭室剪流跨码差 **0.029 %**。

⚠️ **一条反直觉但必须记住的物理事实**：对**薄翼型**加**同厚度**腹板，解析上 GJ 只涨
**+0.42 %（2 闭室）/ +1.76 %（3 闭室）**，**矩形箱恒等不变**（腹板与蒙皮共面时闭室只是被切开，
总扭转刚度不变）。所以「腹板抬高刚度」是个**弱判据**——贴 1 % 阈值会变成掷硬币。
真正区分闭室数的是**剪流**：实测 2 等闭室 `|q|` 比 `[1.0, 0.9009]` vs 解析 `[1.0, 0.8955]`，
3 等闭室 `[1.0, 1.1207, 0.8640]` vs `[1.0, 1.1076, 0.8556]`，腹板承 `|q₁−q₂|` 比值
**0.1011 / 0.1340** vs 解析 **0.1045 / 0.1295**（各相差 10–25 %，量级足够）。
⚠️ 另一个坑：翼盒蒙皮在 **x-z 面**，面内剪力是全局 `sxz`；`post.von_mises_inplane`（给 x-y 平板写的）
会把它**丢掉**（读 0.05 MPa），必须用全分量 `post.von_mises`（读 **6.1408 MPa** vs 解析剪流 6.1361，**+0.078 %**）。

翼盒网格重组算法按模型自适应：无长桁 → 算法 1；有长桁 → 算法 3（blossom 全四边形）。
`recombination_algorithm3` 那条是显式固定算法 3 的对照，用于把「长桁的影响」与「网格算法的影响」分开。

`naca4412_wingbox_str3_T` 为什么有 29447 个节点（基线的 6 倍）：T 形翼缘被腹板切成两条 15 mm
半宽窄条，blossom 全四边形在默认尺寸下直接失败（`1D mesh cannot be divided by 2`）。经 5 种翼缘
宽度 × 3 种尺寸策略的实测扫描（`../feagpt_repro/diagnostics/t5_robustness.json`），把全局网格尺寸
上限钉在 12 mm 才在每个宽度下都稳（minJ 0.49–0.53）。代价就是节点数。

**T1 为什么需要一条尺寸上限**：锥形箱的**后梁是梯形**，锥度 0.6 时最窄处只剩 **43.79 mm**，
而默认 `size_span = 25` 是它的 57 % —— blossom 会挤出针状四边形，实测 minJ 掉到 **0.0437**
（门禁要求 ≥ 0.30），节点跑到 z≈1620 形成 120 mm 长条。解法沿用 T5 的同一个常数：
builder 声明 `mesh_size_cap = 0.4 × 最窄条带全宽`（锥 0.6 → 17.52 mm，锥 0.8 → 23.36 mm，
后掠 20° → 29.20 mm），**只对非等直声明**（等直腹板是矩形，默认尺寸本就干净，声明会重网已发布案例）。
12 组扫描（锥度 × 后掠 × 肋数）：无 cap **6/12** 过，有 cap **12/12** 过。
证据：`../feagpt_repro/_m5_probe/t1_mesh_probe.py`、`t1_cap_probe.py`。
**放量把 cap 压得更低**：强锥 `taper040` 的 cap = **11.68 mm**（最窄腹板 29.2 mm），强后掠
`sweep40` = 29.20 mm —— 全树 minJ 落在 **0.4636–0.6626**，**41 条全部 0 个 tri3**（T7 打样与铝 d20 网格逐字节同构，minJ 0.6084）。
**T6 的腹板不需要 cap**：它在弦向很薄但落在等分弦比上（0.4c / 0.475c / 0.55c），离前后梁都远，
默认尺寸本就干净——沿用 T1/T5 的同一条规矩：**只对窄到默认尺寸撑不住的条带声明 cap**。
三条实测 minJ **0.5467–0.5784**。

**T3 柱壳为什么要求 `n_stringers ≥ 5`（D19）**：1–4 根长桁时框外弧 `r≈998` 处冒出 **16–22 个三角**
（3str/2frm 20、4str/2frm 16、4str/3frm 22）。近因是长桁腹板在 `r = R − h_str` 处切断框扇区的径向边，
留下 `h_frm − h_str = 5 mm` 的半单元残条。五种修法（简单重组 / 只细分框经线 / 蒙皮与框一起细分 /
框专用尺寸场 / 逐面 2-D 算法）**全部实测否决** ⇒ **认下包络** `n_stringers ∈ {0} ∪ [5, ∞)`，
1–4 直接 `raise`。柱壳两条实测 minJ **0.5159 / 0.5211**，0 三角。证据：`../feagpt_repro/_m5_probe/t3_mesh_envelope.md`。

平板为什么用 3 mm 网格：**不是拍的**。收敛研究（`../feagpt_repro/diagnostics/panel_convergence.py`）
把 FE 中心挠度对 Navier 闭式解在 12 / 6 / 3 mm 三个尺寸上量了一遍，相对误差
**−6.9 % / −0.63 % / −0.10 %**（单调向上收敛）。原定 6 mm（误差已进 2 % 门内），
但 6 mm 下无长桁平板的 max|u| 跨求解器差 **0.800 %** 只剩 0.2 个百分点余量，
**D9（2026-10-03）把平板族默认尺寸收到 3 mm**，差值降到 **0.326 %**，
且解析解 0.96268 mm 被 ccx 0.96175（−0.097 %）与 abaqus 0.96490（+0.230 %）**从两侧夹住**；
**容差 1 % 一个字没动**。代价：节点 11761 → 46432。

## 4. `truth.json` 字段

```jsonc
{
  "schema_version": 1,
  "case_id": "...",
  "structure_family": "wingbox" | "stiffened_panel",
  "spec_sha256": "...",          // 输入指纹：spec 变了能查出来
  "topology": {
    "design":            { ... },  // 规格要求的读数（输入读数）
    "geometry":          { ... },  // 几何实际读数（独立读数）
    "expected_geometry": { ... }   // 由 design 推导的应有读数
  },
  "scalars": { "n_nodes": ..., "max_disp": ..., "max_von_mises": ... },
  "solver": "ccx",
  "semantic_gate": { "pass": true, "checks": [ ... ] }
}
```

`topology` 三个块的**字段是结构族相关的**：翼盒给的是
`n_spar_faces / n_skin_faces_upper / n_rib_faces / n_stringer_faces_* / rib_z_planes`，
平板给的是 `n_skin_faces / n_stringer_faces / stringer_stations`。

**关 4 的判据是「派生预期 vs 几何实测」，不是拿 `design` 跟自己比。**

### 4.1 `wingbox` 族的映射（等直翼盒，`n_ribs-1` 个展向舱）

```
n_sec  = 每根长桁的壳面数，由截面定义给出（blade 1，T 3，T 且翼缘宽 ≤ 0 → 1）
n_web  = 中间腹板道数 = len(web_chordwise)            （无腹板时 0）
n_cell = n_web + 1                                    （腹板贯穿上下蒙皮，每道 +1 闭室）
梁面   = n_spars × (n_ribs − 1)
单侧蒙皮面 = (n_stringers + 1) × (n_ribs − 1) × (n_web + 1)
长桁面 = n_stringers × n_sec × (n_ribs − 1)
腹板面 = n_web × (n_ribs − 1)                         （每道腹板被肋平面切成 n_ribs−1 片）
肋面   = n_ribs × (n_web + 1)                         （⚠️ 含根部肋（单列在 root 组，不折回会少 1），且肋面也被腹板切开）
壳面总数 = (n_spars + 2(n_stringers+1)(n_web+1) + 2·n_stringers·n_sec + n_web)(n_ribs − 1) + n_ribs(n_web + 1)
```

**⚠️ 三个「多了个因子」的地方**（实测 `web1`：`n_ribs=5 / n_web=1` ⇒ 38 面 = 梁 8 + 蒙皮 8×2 + 腹板 4 + 肋 **10**）：
① 单侧蒙皮面 ×(n_web+1)：腹板把蒙皮条带切成两段；
② **肋面 ×(n_web+1)：肋面也被腹板切开** —— 这条最容易漏（5 → 10），漏了关 4 立刻咬；
③ 腹板面 n_web×(n_ribs−1)：每道腹板被肋平面切 4 片。
`n_cells = n_web + 1` 本身进 `truth.design`，是「闭室数」这个**语义量**的正规出口 ——
`n_sec` 与它都由 spec 推导，**不是在已建模型上量的**，否则关 4 就是拿构建器验它自己。

**`n_sec` 为什么不能省**：T 形的翼缘会被腹板切开，一根长桁是 3 个面而不是 2 个
（实测见 `../feagpt_repro/diagnostics/t_stringer_probe.py`）。漏掉这个因子，
带缘条的长桁模型会**通过全部数值门禁而语义是错的**。
`n_sec` 由 `feagpt/sections.py` 的截面定义给出，**不是在已建模型上量的** ——
否则关 4 就是拿构建器验它自己。注意它依赖翼缘宽度：`T` 且 `flange_width ≤ 0` 会退化成
blade，此时 `n_sec = 1`（不讲这一条，关 4 会把**正确的**退化构建判成错，见 §5）。

### 4.2 `stiffened_panel` 族的映射（M3/T2 新增）

```
n      = n_stringers
蒙皮面 = n + 1             ← 这个「+1」不是记账约定，是**布尔粘结真的发生了**的观测量
长桁面 = n × n_sec         （blade: n_sec = 1）
壳面总数 = 蒙皮面 + 长桁面
站位   = length × (j+1)/(n+1)，j = 0..n−1   （实测：由每个**腹板**面的包围盒 x 中心读出）
```

**`n + 1` 为什么是实质判据**：蒙皮与长桁条是**贴在一起的两个面**。不做布尔的实测结果是
**共享 0 个节点** —— 三根悬空悬臂，线性静力照样解得出来、三道数值门禁一条都不报警
（`../feagpt_repro/diagnostics/panel_bond_probe.py`）。做了 `occ.fragment` 之后每根条与蒙皮
**共享 51 个节点、3 条边界曲线**，蒙皮被切成 **4** 个面。所以「蒙皮面数 = n+1」正是
「粘结发生了」的可观测证据，关 4 把它算成精确值而不是「接受任意面数」。

**站位也是实测的**：腹板面的特征是**弦向跨度为 0**（翼缘是水平条，不是），站位取包围盒 x 中心。
从包围盒读回来而不是从组名复制，才让「builder 忽略了 `n_stringers`」这件事可被观测到。

这套映射是**结构族相关**的。族是一等公民（`spec.structure.family` +
`feagpt/geometry.py` 的 `BUILDERS` 注册表，未知族直接报错），新结构形式接入时按族重推公式即可，
下游（网格/deck/后处理）一行不用改 —— T2 就是一次实证：`post` 之后没有任何分支。

### 5.1 算法侧 baseline —— 这份数据到底能训出什么（M8，2026-10-24）

完整报告见 **`BASELINE.md`**，数据见 `baseline_d31.json`（此节为 M8/D31 时点）、最新 **`baseline_d34.json`**（含 D34 的二次 `sweep` 基，见 §5.2），脚本 `../feagpt_repro/baseline.py`。
9 个档位 × 4 个目标的 test MAPE（%），**模型选择在 val 上做、test 只报一次**，括号为 4000 次 bootstrap 的 95 % CI：

| 目标 | 常数基线 | 1 参数梁 | 最强物理（val 选） | 最强学习（val 选） | 差值 pp |
|---|---|---|---|---|---|
| `max_disp` 合位移（**= 弯曲挠度**） | 49.06 | 24.84 | M2X 16.58 | **M5 7.96** [2.10, 16.77] | −8.61 [−17.91, −1.54] ✔ |
| `max_w` **展向**位移（z 分量，副指标） | 35.93 | 25.87 | M2X 16.72 | **M5 4.17** [1.35, 8.50] | −12.55 [−30.15, −2.30] ✔ |
| `vM` 中面峰值 | 29.84 | **10.39** | M2L 9.68 | M5 9.51 [2.80, 17.46] | −0.17 [−2.25, +1.55] ✘ |
| `vM` 外表面峰值 | 31.22 | **12.22** | M2L 10.89 | M5 10.68 [3.57, 19.10] | −0.19 [−3.01, +1.80] ✘ |

常数基线 = **MAPE 最优常数**（加权中位数，权重 1/y），比几何平均更强 —— 用它当地板是对学习器不利的取法。

**三条结论（都有实测支撑，不是印象）**

1. **位移可学、应力不可学。** 相对常数基线：`max_disp` **16.2 %**（弯曲挠度）、`max_w` 11.6 %（展向）；两个 `vM` 目标只有 31.9 % / 34.2 %。
   **应力上 1 参数闭式解已经到顶**（`F·span/(t·c²)` 配一个常数 = 10.39 % vs 最优学习器 9.51 %，差 0.88 pp），
   配对 bootstrap 的 CI 跨 0 ⇒ **在应力上加特征、加样本已经没有收益**。
2. **`max_disp` 就是弯曲挠度，`max_w` 是展向位移 —— 别拿 `max_w` 当代理目标。**
   本 deck 的 **z 轴是展向**（0–2002 mm）、载荷是 `*CLOAD, DOF 2` = **y**，所以 `max_w` = `max|DISP[2]|` 是展向分量；
   实测 **`max|v|/max_disp` = 0.99899–0.99973**（15 条，浮动 0.07 %）⇒ `max_disp` 已经就是弯曲挠度。
   `max_w` 的 4.17 % 低于 `max_disp` 的 7.96 %，真因是**它对 `sweep` 不敏感**：`sweep40_taper040` 上
   `max_disp` 放大 **×4.171** 而 `max_w` 只 **×1.716**（敏感度 41 %），幂指数也不同（span^**2.90** vs span^**1.95**）。
   **同一组样本比较**（都下掉 `sweep40`）：`max_disp` **3.82 %** < `max_w` **4.48 %**。
   ⇒ 跨目标比 MAPE 必须下掉同一条样本；各自剔各自最差会得出相反结论。
   诊断脚本 `../feagpt_repro/_probe_m9/diag_w_vs_disp.py` → `w_vs_disp_diag.json`。
3. **误差几乎全部集中在 `planform_out`。** 按外推机制分组（M5 / `max_disp`）：`planform_out`（sweep 40° 出上界 20°）
   **32.9 %**，而 `webpos_new` 6.3 / `section_new` 5.3 / `combo` 4.6 / `size_out` 2.0 / `ribs_new` 0.0。
   去掉各自最差 1 条后 M5 只剩 **3.81 %**（中位 5.26 %、最大 32.9 %）
   ⇒ **报 MAPE 必须同时报中位数与最大值**，7 个点里 1 个离群点就能抬高 4 pp。

**为什么应力不可学**：31 条翼盒里 `max_disp_node` 有 **21 个**不同节点，`vM` 中面峰值位置有 **25 个**不同节点。
位移场平滑（位置偏一点值几乎不变），应力场在孔边/角点梯度陡（位置错就值错）——
**峰值是「离散选择」而非「光滑泛函」**，这既解释了上面的结论，也说明继续给 vM 峰值补样本基本是白费。

**另外三族仍不可建模**：`open_hole_panel` train 2 / `fuselage_barrel` 1 / `stiffened_panel` 1 条，
任何档位都拟合不起来。它们的价值在**求解器验证**（开孔板有 Kt/Howland 闭式解），不在训代理模型。

### 5.2 D34：改模型形式 —— 修好了 `sweep` 主效应，修不好交互（2026-10-24）

**动因**：D33 补了 30° 站，但 40° 仍是全表最大误差项（25.7 %）。物理侧实测说这不是样本不够，是**形式不对** ——
`log y` 对 `sweep` 一直是线性的，而实测响应超线性（相对 0° 的位移比 1.000 / 1.094 / 1.340 / 1.853 / 2.965，
增量严格递增）。**线性函数不能弯。**

**做法**：`sweep` 列换成 `[s, s²]`（`s = sweep_deg/20`，**过原点**：无后掠时修正恰为 0）。
新增 `M3q` / `M5q` 两档，`lin` 档原样保留作对照。完整判据与表格见 `BASELINE.md` §2.5。

| 指标（`max_disp`，M5 档） | 线性 | 二次 | Δ |
|---|---|---|---|
| `LOO@30`（**零泄漏主判据**） | −22.14 % | **−1.07 %** | +21.1 pp |
| `val` 单点 `sweep40` | −34.54 % | **−3.17 %** | +31.4 pp |
| `planform_out` 组 | 25.70 % | **15.70 %** | −10.00 pp |
| test MAPE | 7.74 % | **6.18 %** | −1.56 pp（CI 跨 0，**不显著**） |
| test 最大 APE | 25.70 % | **15.70 %** | −10.00 pp |
| train LOO 整体 | 4.19 % | **2.14 %** | −2.05 pp |

**三条边界，都必须一起引用：**

1. **只在 `max_disp` 上采纳。** 同样改动在 `max_w` 上 val 6.01 → **1.93**（好看）但 test 8.33 → **13.49**、
   最大 APE 26.8 → **65.1 %**（崩）；两个 `vM` 目标同样 test 恶化。**一个形式不能通吃四个目标。**
2. **`val` 不足以选形式（D34-b）。** 4 个目标上 `val` **一律**选中二次基，`test` 只在 `max_disp` 上支持它。
   `val` 只有 7 条、`sweep>0` 仅 1 条且是 taper 中性的（二次基最擅长的场景）。⇒ 形式类决策用
   **「留最高站位」LOO**，D32 的「val 选」仍适用于**档位**选择。
3. **剩余 15.7 % 不是形式问题。** train 中「`sweep>0` 且 `taper≠1`」的样本 = **0 条**
   ⇒ 交互项 `s²·(taper−1)` 恒等于零，**不是估不准而是不可估**。残差结构：taper 中性 −3.17 %、
   两个 taper 角点 +13.31 / +15.70 %。**换任何基都学不到，只有补一条带锥度的后掠算例。**

**顺带查出的数据缺陷**：`n_web` 与 `web_pos` 在 train 上**完全共线**（奇异值 1.3e-15，train 只有 1 条
带腹板算例 ⇒ 两列都只在同一行非零），`is_T` 恒为 0 ⇒ **10 个特征实际只有 8 个可辨识方向**。
这解释了 M7「`n_web` 1→2 外推 +14.5 % 为第二不稳轴」—— 那条路在 train 上根本没有信息。

6. **应力口径未统一**（高，**本轮已量化到机制**）：关 3 里两码的**峰值** von Mises 差
   16–19 %（翼盒），而逐节点场中位差只有 0.12–0.59 %（这就是判 PASS 的依据），p90 可到 20–58 %。
   本轮把机制钉死了，有两条**各自都是对的**、但不可比的口径：
   - ccx `*EL FILE, OUTPUT=2D` 写**全 6 分量**张量，所以它的「von Mises」**含横向剪切**
     `SYZ/SZX`；Abaqus 的膜平均只由 `S11/S22/S33/S12` 构成，**不含**横向剪切。
   - 平板上这个差异就是**全部答案**：峰值节点的张量实测是
     `(2e-05, 2e-05, 5e-05, 0.0, −0.19867, 0.67184)` —— 面内分量是 0（对：线弹性平板纯弯
     无膜作用），1.21 MPa **全部**是剪切。同一条 3 mm 网格上两码一致性地给出中面应力 0。
   - **但「把 ccx 也削成面内」并不能让两码更接近**：翼盒上实测
     `ccx 全量 vs Abaqus 膜 = 中位差 0.33 %`，而 `ccx 面内 vs Abaqus 膜 = 4.90 %`。
     假设被数据否定，所以**已登记的判据（全量 vs 膜）没有被改**（9 条翼盒是它验过的）。
   - **更硬的证据是：两棵树里同名同路径的 `scalars.max_von_mises` 指的不是同一个量。**
     平板算例上 `modeling/`（ccx）记 **1.2135**（节点全张量、剪切主导），`_xval/`（abaqus）
     记 **0.0**（中面膜值），另有 `max_von_mises_peak` = **3.1952**（外纤维）。
     **下游按同名取数会得出「Abaqus 侧零应力」。** 两码峰值相差 **62.0 %**（1.2135 vs 3.1952），
     而这 62.0 % 是**定义差异，不是分歧**。
   - 平板这类纯弯模型里唯一有物理意义的是**外纤维值**（≈弯曲应力）；但要注意
     **ccx 侧目前没有可与它对应的数** —— ccx 印出来的就是剪切主导的那个 1.2135，
     所以现在「外纤维值可比」只有一侧。
   - → **D8 已拍板（2026-10-03）：归档口径 = 外表面峰值**。ccx 走 `OUTPUT=3D` 展开壳 +
     `post.collapse_expanded_shell` 折回中面，外纤维留在 `STRESS_PEAK`；中面值另存
     `max_von_mises_midsurface`，并带 `max_von_mises_definition: "outer fibre"`。
     两棵树现在**同名同定义**，`verify_dataset.py` 把「定义存在且是外纤维」当硬闸。
     但**归约方式**仍是两码各自的选择（ccx 展开壳逐节点平均 / abaqus 截面点外插逐节点平均
     + 另一个逐单元最大值），所以**峰值跨码仍不可裸比**，判据是逐节点中位差。
     上面这段保留为机制记录。
7. **两个求解器对「力」的约定不同**（本轮实测，已写进 `verify_solvers.py` 的
   `FORCE_CONVENTION`）：ccx 的 `FORC`（`*NODE FILE, F`）是节点**总外力**（自由节点=外载，
   约束节点=反力），全模型求和**恒为 0**；Abaqus 的 `RF` 是**纯反力**，全模型求和**等于外载**。
   两者只在「支撑集不承担外载」时相等 —— 翼盒（500 N 在自由翼尖）成立，**分布压力不成立**
   （实测同一 36 N 载荷：ccx 求和 −0.00001 N，Abaqus 求和 +36.00000 N）。
   把它们当同一个量，会让一个平衡到 1e-5 的平板报出 **100 % 平衡残差**。

18. **`eqc`（ccx 平衡残差）在进展看板上换过一次口径（2026-10-06）**：翼盒那 23 行原是从**更早一版**
    `verify_solvers.py` 抄的（基线写 0.000034 % 而现工具报 0.000485 %）。
    同一列混两种口径正是「同一列两个口径」的静默漂移，已用现工具**整列重测**
    （`_m5_probe/refresh_eq.py` → `_dash_eq.json`，7 行数字随之更新）。
19. **开孔板的双维角点在 D28 声明前会落错 split（D28，2026-10-08，入库前补上）**：
    `HOLDOUT_REGIONS` 按**「首个命中」**匹配，D28 之前「λ 与 (L,W) 同时 ≠ 锚点」的点会先撞上
    λ 单维 val 谓词、落进 val —— 与柱壳 D25 声明前同款缺陷（D16/D25/D28 同类，声明必须先于数据）。
    处置 = 双维谓词插在偏心 test 之后、两个 val 谓词**之前**（锚点 λ 0.1 / 400×200，两轴都用 `!=` 而非 `>`，
    对齐 D25 读法；`!=` 是为了 λ 向下的点不被 `>` 漏接）。探针验证：d18/λ=0.09（λ 向下 + 尺寸变）
    正确落 test、仅 λ 向下正确落 train、不误伤锚点（`check_forms :: T4.role-and-split` 5 → 11 条）。
    **厚度维本轮不声明**（拍板：对齐平板族 D16 口径）：厚度 ≠ 2 mm 而居中、λ 不变的点将按默认落 train，
    数据集暂无此类点；`make_manifest` limitations 已记账，后续放量厚度维须先补声明。

    Howland 闸沿用 verify_hole 口径**只打 ccx**，abaqus 峰值对 Howland 的 −2.98 % 是恢复路径偏差
    （基线自身 −1.48 %），只印不判（D8/D23 同一条纪律）。
    **平板 / 柱壳 / 开孔板三族未纳入**：它们的载荷是分布压力 / 内压，`--reaction-set clamp` 的口径对它们不成立，
    要用各自的目标值（见 §7.7）。
20. **`sweep` 是全库唯一「外推就崩」的轴（M7，2026-10-24，实测）**：`n_ribs` 5→7/9 只差 −1.9/−2.8 %、
    `is_T` 新截面 +4.8 %、`n_web` 1→2 +14.5 %、`taper` 0.6→0.4 −11.1 %，但 **`sweep` 20°→40° 差 −41.5 %**
    且**超线性**（不是标度律能外推的量）。所以 sweep 只能当**内插评测**用，不能拿 20° 的模型去预测 40°。
21. **D31 八条的 `vmm` / `vmf` 两格没有值，是「没导出」不是「没测」**：`vmm`（per-element 峰）与
    `vmf`（node-averaged 峰）来自 `odb.json` 的 `meta.stress_candidates_max_vm`，而这一批 abaqus 结果是
    **手工 bat** 跑的（规避沙箱注入 `tsbx.dll` 的老问题），那个上传器只导出 `STRESS` 场、不导出两个候选口径。
    处置：看板的逐条双码明细表**不收这 8 条**（该表本就不收全量翼盒），8 条的位移 / 平衡 / 逐节点应力场
    读数全在 `_xval_m8.json`；**不拿 `max_von_mises` 去填这两格**——那会把两个不同定义的数字混成一列（§7.18 同款事故）。
22. **手工 bat 的产物流程是「先 resummarize 再 make_dataset」，顺序反了不会报错**：
    手工 bat 只产 `<case>.odb.json`，`make_dataset` 找不到 `<case>.results.json` 时会**照常导出六件套里的五件**
    并在摘要里打 `max|u|=n/a` —— 是提示，不是闸。本轮就这样先在 `_xval` 落了 8 个缺 `model.results.json`
    的目录。收口时必须**逐目录数文件（6 个）**，别只信 `gate4 semantic: 8/8 PASS`。
